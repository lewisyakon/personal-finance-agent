# ADR 0001：阶段 11 采用普通本地 Web 发行

- 状态：Accepted
- 日期：2026-09-20

## 决策

阶段 11 使用 Docker Compose 运行 FastAPI 和静态 Vue/Nginx，浏览器只通过宿主机
`127.0.0.1:5173` 访问。后端调试端口也只绑定 `127.0.0.1:8000`。持久数据保存在显式
`PFA_DATA_DIR`，不存入容器层。

## 原因

普通 Local Web 复用现有前后端实现，备份恢复和升级边界清晰，并能用回环端口、Host 白名单和
容器权限约束实现当前威胁模型。PWA 的 Service Worker 会引入敏感页面缓存生命周期；Tauri 会
增加桌面运行时、签名和平台打包工作，而阶段 11 没有需要原生系统 API 的需求。

## 后果

- 用户需要 Docker 和本机浏览器。
- 页面离线资源由当前 Nginx 容器提供，但不安装为 PWA，不使用 Service Worker 缓存。
- 后续如需系统密钥环、桌面文件选择器或签名安装包，应新增 ADR 评估 Tauri，而不是改变当前
  数据目录和备份合同。
